
Project title:
  HTML resume page - Hamja Sultan

Project Description :
  As described in the project brief, this assignment is an HTML resume page created by replicating the given format using my own personal information. The objective of this project is to demonstrate correct HTML structure, proper use of tags, and semantic markup.

 Technologies used:
  - HTML
  - CSS (for basic styling)

 Concepts used:
  This project focuses on writing clean, readable, and well-structured HTML code. Semantic tags are used to improve clarity, accessibility and structure of the document.

  Common HTML elements used in this project include headings (h1, h2, h3), paragraphs (p), text emphasis (strong), and table-related tags (table, thead, tbody, tr, td) to organize content effectively.

Page structure:
  - header is used to display personal information
  - main contains details like education, skills, and experience etc
  - footer includes contact details and copyright information
